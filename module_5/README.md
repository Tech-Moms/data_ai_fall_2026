# Module 5: Storytelling with Data using Looker 

## Overview

In this module, students will explore Looker, a powerful business intelligence tool that allows users to explore, visualize, and share data insights. The first part of the module focuses on dashboard creation: students will learn to use Looker's visual interface to build insightful, interactive dashboards. By the end of Part 1, students will be able to connect to data sources, explore data using Looker's tools, and design professional dashboards to support data-driven decision-making.

In the second part, students will learn the fundamentals of data storytelling: how to turn those dashboards into compelling narratives that inform and inspire an audience.

## Learning Outcomes

**Looker Data Studio**

- Navigate the Looker interface
- Connect Looker to a data source and explore data
- Build and customize dashboards
- Apply filters for interactive dashboard elements
- Share dashboards

**Storytelling with Data**

- Explain the purpose of data storytelling and its role in decision-making
- Select and design effective data visualizations for clarity and impact
- Craft cohesive narratives that contextualize and highlight key insights
- Implement ethical and inclusive practices in presenting and interpreting data

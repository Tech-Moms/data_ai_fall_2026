# 🌱 Mindset Moment: "Not Yet" Cards (15 min)

**Supplies:** 3x5 index cards (2 per person), pens, tape 📝

**1. Write It Down (3 min)** 💭
On **Card 1**, everyone anonymously writes one limiting belief they've had about learning tech. Examples:
- "I'm not a math person."
- "Everyone else gets this faster than me."
- "I'm too old to switch careers."

**2. Swap & Reframe (5 min)** 🔄
Collect the cards, shuffle, and pass them back out so everyone gets someone else's card.
On the **back**, write a kinder, truer version, using the word **"yet"** if it fits:
- "I don't understand SQL **yet**."
- "Everyone learns at their own pace, and I'm learning mine." 💪

Read a few out loud. Then everyone keeps the card they reframed as a reminder that others are feeling it too. 💜

**3. Proof Card (5 min)** 🏆
On **Card 2**, write: **"Something I can do now that I couldn't do in August."**
Tape them all up on a **Proof Wall** and take a group photo! 📸

**4. Error Messages Are Feedback (2 min)** 🚨➡️💡
Quick reminder before Bingo: every developer sees errors all day. An error is SQL telling you *exactly* what to fix next!
